# Suno Studio Releases

Kênh phân phối và cập nhật ứng dụng chính thức của **Suno Studio** (Android Native).

### Bản phát hành mới nhất: [v0.5.9](https://github.com/hoangqh23/suno-releases/releases/tag/v0.5.9)

### Nhật ký thay đổi (Changelog):
• Khắc phục hoàn toàn lỗi văng ứng dụng khi bấm mở app: sửa Proguard Keep Rules cho nhân native yt-dlp & FFmpeg
• Tối ưu khởi động: chuyển sang cơ chế nạp thư viện theo yêu cầu (Lazy Loading), an toàn tuyệt đối 100%
• Tích hợp tải nhạc/video đa nền tảng yt-dlp (hỗ trợ YouTube, TikTok, SoundCloud, Facebook...)
• Tùy chọn tải đa định dạng: MP3 320kbps, M4A, WAV, FLAC, Video MP4 và Trọn bộ (All-in-One)
• Nút 'Cập nhật yt-dlp' ngay trong app để luôn tải mượt mà không lo YouTube chặn
